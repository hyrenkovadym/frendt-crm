# FRENDT CRM — сервер із базою даних

Без зовнішніх залежностей: потрібен лише **Node.js 22.5 або новіший** (база SQLite вбудована в Node.js).

## Запуск
```
npm start
```
або
```
node --experimental-sqlite --no-warnings server.mjs
```
Відкрити: http://127.0.0.1:4173

## Налаштування (змінні середовища)
| Змінна | Що означає | За замовчуванням |
|---|---|---|
| `PORT` | порт | `4173` |
| `HOST` | адреса; на сервері в інтернеті — `0.0.0.0` | `127.0.0.1` |
| `DATA_DIR` | папка з базою `frendt-crm.db` і резервними копіями | `~/FRENDT-CRM-data` |

## Що де зберігається
- `DATA_DIR/frendt-crm.db` — база: заявки, клієнти, доповнення довідників, журнал змін (`history`).
- `DATA_DIR/backups/` — резервна копія при кожному запуску та щодня, зберігаються 30 останніх.
- Якщо в `DATA_DIR` лежить старий `data.json`, а база порожня — дані імпортуються автоматично.

## VPS (Ubuntu)
```
# Node.js 22
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash - && sudo apt install -y nodejs
# запуск як служба
sudo npm i -g pm2
HOST=0.0.0.0 PORT=4173 pm2 start "npm start" --name frendt-crm && pm2 save && pm2 startup
```
Далі — домен і HTTPS через nginx/Caddy (проксі на порт 4173).

## Render
- Build command: *(порожньо)*, Start command: `npm start`
- Поточне тестове розгортання працює на Free з `HOST=0.0.0.0` і тимчасовою папкою даних.
- Для постійного зберігання треба перейти на платний план і підключити **Persistent Disk** з mount path `/var/data`.

## Вхід працівників
- Без входу сервер не віддає жодних даних: сторінка показує лише форму входу.
- **Перший адміністратор:**
  - на Render — змінні `ADMIN_LOGIN`, `ADMIN_PASSWORD`, `ADMIN_NAME`; також підтримуються наявні `CRM_USERNAME` і `CRM_PASSWORD`;
  - на своєму комп'ютері — просто відкрийте http://127.0.0.1:4173 і створіть адміністратора у формі (з інших комп'ютерів це заборонено).
- Далі адміністратор додає менеджерів: натиснути на своє ім'я вгорі справа → «Працівники».
- Менеджери вносять і ведуть заявки та клієнтів; видаляти заявки/клієнтів, керувати працівниками й імпортувати таблицю може лише адміністратор.
- Паролі зберігаються як хеш scrypt, вхід діє 30 днів, після 10 невдалих спроб за 15 хв вхід з цієї адреси блокується.
- У таблиці `history` записується, хто що змінив.

## Перше заповнення
При першому запуску сервер один раз завантажує з `seed.json` усі заявки та клієнтів з таблиці «Облік заявок FRENDT». Далі цей файл не використовується.
